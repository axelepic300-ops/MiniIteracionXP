## Reflexión

### 1. ¿Qué ventaja tuvo escribir primero los casos de prueba?
Permitió tener claro desde el inicio qué resultados debía dar el programa y detectar errores más fácilmente.

### 2. ¿Qué aportó trabajar en pareja?
Ayudó a revisar el código mientras se desarrollaba, compartir ideas y detectar errores que una sola persona podía pasar por alto.

### 3. ¿Fue fácil incorporar el nuevo requerimiento?
Sí, porque el código era sencillo y ya contábamos con pruebas para comprobar que el cambio no afectara el funcionamiento anterior.

### 4. ¿Qué práctica de XP facilitó más el cambio?
La práctica que más facilitó el cambio fue TDD, porque las pruebas permitieron modificar el código con mayor seguridad y comprobar que todo siguiera funcionando correctamente.
